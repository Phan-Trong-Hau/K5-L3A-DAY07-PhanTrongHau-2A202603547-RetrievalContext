# Đánh giá agent trên Nghị định 13

Lần đánh giá hiện tại dùng nguồn tiếng Việt Nghị định 13/2023/NĐ-CP đã nhập ở Day 06; không dùng Alice. Bản PDF ký số, OCR, câu hỏi và nguồn gốc được lưu tại `data/nd13/` và `benchmark/nd13_questions_source.json`. Chỉ số chi tiết, hạn chế và trace ở [báo cáo demo](../report/NGHI_DINH_13_DEMO.html) và `results/nd13/`.

## Dữ liệu và protocol

- Nguồn: bản ký số năm 2023, 39 trang scan; OCR tiếng Việt từ Day 06.
- Snapshot có 88 đoạn paragraph (tối đa 1.000 ký tự), 384 chiều, BGE-small-en-v1.5; chunk giữ `nd13`, trang PDF vật lý, chương và offsets. Hash trong `data/nd13/provenance.json`.
- Benchmark: 20 câu external test đóng băng từ Day 06. Tất cả câu đều có đáp án trong nguồn; câu hỏi, expected answer và evidence nằm trong file source. Không có dev set ND13, không chọn winner hoặc chỉnh tham số trên các kết quả này.
- Cả 5 phương pháp dùng cùng Qwen 3 4B local, cùng context window, cùng controller tiếng Việt và cùng câu hỏi/filter. Mỗi phương pháp chạy đủ 20 câu.
- `hit3` tính trên ranking truy vấn nguyên bản; `context_hit` tính evidence có trong context cuối sau các lượt tìm kiếm của agent. Hai số không tương đương với câu trả lời đúng.
- Unit tests là bộ test code dùng mock; chúng không thay cho đánh giá chất lượng model.

## Chạy lại

```bash
.venv/bin/python scripts/prepare_nd13.py
.venv/bin/python scripts/run_nd13.py
python3 scripts/check_tests.py
.venv/bin/python scripts/build_nd13_report.py
```

`run_nd13.py` lưu mỗi trace ngay sau khi hoàn thành từng câu tại `results/nd13/test/<method>/traces.json`; có thể chạy lại cùng lệnh để tiếp tục nếu source/config/code hash không đổi.

Hỏi agent trực tiếp bằng tiếng Việt (mặc định chọn Nghị định 13):

```bash
.venv/bin/python scripts/ask.py "Trong Chương I, dữ liệu cá nhân được chia thành hai nhóm nào?"
```

Có thể chọn `--config baseline|lexical|hybrid|mmr|rerank`, `--chapter I` khi người dùng nói rõ chương, `--output` để lưu trace khác. `--dataset alice` chỉ dành cho benchmark cũ.

Phát lại các case demo đã lưu mà không gọi model mới:

```bash
python3 scripts/demo.py --version nd13 --scenario all
```

## Giới hạn

BGE-small-en-v1.5 và MiniLM cross-encoder là model có tên/huấn luyện gốc tiếng Anh; lần này giữ nguyên model Day 06 khi truy vấn tiếng Việt. OCR giữ lỗi nhận dạng của bản scan. Đây là benchmark retrieval/agent trên bản ký số năm 2023, không phải tư vấn pháp lý hay khẳng định luật hiện hành.
